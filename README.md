# LabCoat
An action-adventure game that starts with a scientist who mysteriously disappears which is investigated by a technician. They are sent to turn the main laser off, but some kind of extraterrestial organisms have taken over the lab.

## Objective
Turn off the main laser and escape from the lab

## Keybinds
WASD / Arrow Keys — Mobility (Forward, Left, Back, Right)

Mouse Movement — Pitch & Yaw Aiming

Left Mouse Button (Hold) — Fire Handheld Alignment Laser

Right Mouse Button / Q — Deploy Portable Tripod Mirror

F — Toggle Flashlight (Suit Headlamp)

E — Interact (Examine Polaroid, Play Audio Logs, Flip Breakers, Pull Lever)

M / TAB — Toggle Facility Schematic Map

Shift (Hold) — Sprint Propulsion

Space — Low-Gravity Jump

R — Restart at Checkpoint

Escape — Pause / Resume
